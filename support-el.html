Υποστήριξη Διαδρομή Ενέργειας

Είμαστε εδώ για να σας βοηθήσουμε να απολαύσετε το Διαδρομή Ενέργειας!

Χρειάζεστε βοήθεια; Χρειάζεστε βοήθεια; Ανατρέξτε στις συχνές ερωτήσεις παρακάτω ή επικοινωνήστε απευθείας μαζί μας.

Συχνές ερωτήσεις

Πώς μπορώ να επαναφέρω τις αγορές μου;

Για να επαναφέρετε τις προηγούμενες αγορές σας, μεταβείτε στο μενού Ρυθμίσεις της εφαρμογής και πατήστε «Επαναφορά αγορών». Αυτό θα επαναφέρει όλα τα ξεκλειδωμένα κεφάλαια ή άλλες μη αναλώσιμες αγορές που είναι συνδεδεμένες με το Apple ID σας. Σημειώστε ότι οι αναλώσιμες αγορές (όπως οι πόντοι υποδείξεων) δεν μπορούν να επαναφερθούν.

Πώς μπορώ να συγχρονίσω την πρόοδό μου σε όλες τις συσκευές;

Το Διαδρομή Ενέργειας συγχρονίζει αυτόματα την πρόοδό σας σε όλες τις συσκευές Apple χρησιμοποιώντας το iCloud. Βεβαιωθείτε ότι έχετε συνδεθεί στον ίδιο λογαριασμό iCloud σε όλες τις συσκευές και ότι το iCloud είναι ενεργοποιημένο για το Διαδρομή Ενέργειας στις Ρυθμίσεις της συσκευής σας > [Το όνομά σας] > iCloud.

Πώς μπορώ να επαναφέρω την πρόοδό μου στο παιχνίδι;

Μπορείτε να επαναφέρετε την πρόοδό σας στο παιχνίδι από το μενού Ρυθμίσεις μέσα στην εφαρμογή. Πατήστε "Επαναφορά προόδου" και επιβεβαιώστε την επιλογή σας. Σημειώστε ότι αυτή η ενέργεια δεν μπορεί να αναιρεθεί και θα επαναφέρει όλα τα επίπεδα που έχετε ολοκληρώσει, τα αστέρια και τα στατιστικά σας.

Έχω κολλήσει σε ένα επίπεδο. Πώς μπορώ να λάβω βοήθεια;

Το Διαδρομή Ενέργειας προσφέρει ένα σύστημα υποδείξεων για να σας βοηθήσει να περάσετε τα δύσκολα επίπεδα. Μπορείτε να χρησιμοποιήσετε πιστώσεις υποδείξεων για να αποκαλύψετε τη λύση βήμα προς βήμα. Οι πιστώσεις υποδείξεων μπορούν να αγοραστούν μέσα από την εφαρμογή. Εάν εξακολουθείτε να έχετε κολλήσει, μη διστάσετε να επικοινωνήσετε μαζί μας!

Πώς μπορώ να αλλάξω τη γλώσσα της εφαρμογής;

Το Διαδρομή Ενέργειας ακολουθεί τη ρύθμιση γλώσσας της συσκευής σας. Για να αλλάξετε τη γλώσσα, μεταβείτε στις Ρυθμίσεις της συσκευής σας > Γενικά > Γλώσσα & Περιοχή και επιλέξτε τη γλώσσα που προτιμάτε. Η εφαρμογή υποστηρίζει 45 γλώσσες.

Πώς μπορώ να αναφέρω ένα σφάλμα ή να προτείνω μια λειτουργία;

Μας αρέσει να ακούμε τις απόψεις των παικτών μας! Στείλτε μας email στη διεύθυνση contact@yasserhamek.com με λεπτομέρειες σχετικά με τυχόν σφάλματα που αντιμετωπίζετε ή λειτουργίες που θα θέλατε να δείτε. Αν αναφέρετε ένα σφάλμα, συμπεριλάβετε το μοντέλο της συσκευής σας και την έκδοση iOS.
